Someone shared their Muninn code

Muninn is a free private messenger for Android: messages, photos, voice, groups and calls, end-to-end encrypted. There are no accounts and no phone numbers, and nothing is kept on any server. Its twin, Huginn, does the same on desktops and handhelds (.exe or Flatpak), and the two talk to each other.

I have Muninn: open it

Don't have Muninn yet?

Get it on this phone, then come back to this page.

Download Muninn for Android
  1. Open the downloaded file. If Android asks, allow installs from your browser. Play Protect may say it doesn't know this app: tap More details, then Install anyway. Muninn updates itself after this.
  2. Open Muninn and finish setting up.
  3. Come back here and tap I have Muninn: open it. The code works for an hour from when it was shared.

No internet? Ask them to tap Share the app in Muninn: it sends Muninn itself by Quick Share or Bluetooth.

On a computer or handheld?

Huginn is the companion of Muninn, for desktops and handhelds: get it for Windows or as a Flatpak.

  1. Download Huginn below and open it.
  2. Open Huginn, then + and Add someone, then paste the code below.
Huginn for Windows (.zip) Huginn for Linux (Flatpak)

Windows: unzip it anywhere and run Huginn.exe, nothing to install. Flatpak: open it to install.

The first time, Windows may say "Windows protected your PC", because Huginn.exe has no paid code-signing certificate. Choose More info, then Run anyway. To check the download really came from this project, see how to check a download.

Updating by hand? Keep the data folder beside Huginn.exe: it holds your identity, contacts and chats.
