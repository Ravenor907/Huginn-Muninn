# Using Huginn with a controller or TV remote

Huginn works with a game controller as well as a mouse and keyboard, which helps on a TV or a handheld. There is no
separate controller mode: the controller works in the normal layout, which follows the screen (one column upright,
the rail layout sideways). Huginn checks for a controller only while one is connected.

The button legend along the bottom is hidden at first. Press **Select** (View or Back) to show it, and Select again,
or any other button, to hide it. The legend always lists what each button does on the page in front, Y included.
Hints about buttons only show while a controller is in use.

| Button | What it does |
|---|---|
| D-pad | Move the highlight, from the last thing highlighted or clicked |
| A | Open, choose, or write a message |
| B | Back |
| X or LT | The menu of what's highlighted (the same menu as its three dots and a right click) |
| Y | Depends on the page: hold to record a voice message in a chat, Look again in Files, the on-screen keyboard while typing |
| LB | Next section (hold LB and press D-pad left or right to go back or forward) |
| Left stick | Scroll |
| Right stick | Move the pointer (it hides after a few seconds) |
| RB or R3 (right stick click) | Click |
| RT | Right click |
| Select (View) | Show or hide the button legend |
| Menu | Settings, everywhere |
| L3 + R3 (hold) | Panic lock (Ctrl+Shift+Q on a keyboard) |

## One menu per item

Every person, chat, group and member has one menu, and the mouse and the controller get the same one: the three dots
(⋮) beside it, a right click, X or LT. Bigger groups of choices open a sub-page; B there goes back to the menu.

- A contact: Message, Call, Video, Edit (nickname, note, color), Folders and role, What they can do, Chat (pin, mute,
  archive, mark unread, pinned messages, shared), Check safety code, Introduce, Block, Remove.
- A group: Call everyone, Call some people, People, Add people, Channels, Group settings, Leave.
- A group member: Message or Add as contact, Make or remove admin, Make owner, Remove from group. A on a member opens it too.

Things that can't be undone sit last in a menu, in red, and ask first.

## The rail

Chats and your groups sit at the top of the rail. Contacts, Files and Settings are always at its foot, with
the power button (lock or close). LB steps through them. Calls show in their chat or group, among the messages.

## Pages

| Page | A | X or LT | Y |
|---|---|---|---|
| Chats list | Open (a folder: fold or unfold) | The person's or folder's menu | |
| A chat | Write (Yes on a Keep in touch question) | A picked message's options, otherwise the person's menu | Hold to talk |
| Typing a message | Send | The box's options (emoji, pictures, a file) | Keyboard |
| A group's channels | Open or join | The group's menu | |
| A group's members | The member's menu | The member's menu | |
| Contacts | The person's menu | The person's menu | |
| Files | Send files, or send to the highlighted device | Look again, Direct connect, Clear | Look again |
| Settings | Open, or change the highlighted row | | |

In Settings › About, A on the raven ten times turns Labs mode on or off. Labs adds Report a bug (also in the Chats
list's menu): the D-pad moves between Include screenshot, the text and Send, A uses the highlighted one, B closes.
Labs reports (on the Labs computer, in the same menu): Up and Down pick a report, A replies, X deletes, B closes.

The pattern lock works with the D-pad: move to a dot, A starts there, move on through the dots, A again when done. B starts over.
While setting a lock, LB switches between Pattern and Password.

A mouse and keyboard work too (Tab and Shift+Tab switch sections, Page Up and Page Down scroll).

## The desktop panels

Sideways, Huginn looks like Discord: the rail, the list beside it, the conversation and a group's member list.
Everything there works with a controller too:

- D-pad left and right move between the list, the conversation and the member list. A hidden list or member
  list (Ctrl+Shift+L, Ctrl+Shift+U) opens again while the controller's highlight is in it.
- A on a TEXT or VOICE heading folds that category away, and A again opens it.
- In a voice room, A on the room has Mute, Deafen and Leave. The voice panel at the foot of the list has them too
  (click it with the right stick's pointer).
- Push to talk (Settings › Calls) is a keyboard key: it works while Huginn is in front.
- Huginn opens in a normal window that keeps its size and place. F11, or Settings › Look › Open full screen,
  switches to full screen. A handheld's game mode is always full screen.

## Calls and files

- In a call, A mutes, Y changes the output and B ends the call. B asks first: the first press shows "Press B again
  to hang up" for 3 seconds, and a second press in that time hangs up. On a voice call X does the same as B; on a
  video call X turns the camera on or off. On a keyboard, Esc or Backspace is B and Space mutes.
- In Files, Direct connect and Clear are in the menu (X or LT, or the three dots). While files are being sent, B asks
  first too ("Press B again to cancel").

Ctrl+/ lists every keyboard shortcut.
